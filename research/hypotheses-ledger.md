- Claim: a niche-constrained agent produces FEWER out-of-burrow actions than a generalist
  on the same task.
- Measure: out-of-scope actions per task (from result records + MIC-31 axis tags).
- Verdict rule: ≥2 of the first 3 paired tasks confirm → H1 stands; else → D-01 re-forge.

## H2 — Document coordination survives without an orchestrator at N=4
- Claim: the four founding charters coordinate a full task with ZERO live messages —
  documents only.
- Measure: orchestration violations (any live-chat decision that should have been a doc).
- Verdict rule: zero violations in the first full task → H2 stands.

## H3 — External gates actually catch cheats/overclaims

- Measure: gate re-run verdicts vs claimed verdicts.
- Verdict rule: if 5 consecutive runs pass with zero catches AND zero overclaims, the
  gate is either perfect or decorative — inspect manually, then rule.

## H4 — Council pre-judgment changes (improves) plans

- Verdict rule: 3 RJs with zero binding conditions adopted → council is theater → D-04.

## H5 — K-line memory produces measurable reuse
