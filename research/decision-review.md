# Decision review — ADR ledger (every major decision vs alternatives + falsifier)
> 2026-09-06 · the under-zero polish: no decision stands without alternatives and a
> falsification criterion. Format: D-NN · decision · alternatives rejected · why · falsifier.

## D-01 — Niche law (every entity is a niche or not born)
- Alternatives: one generalist agent · loose role labels (crewAI style) · capability-teams.
- Why: Gause (exclusion) + Ricardo (comparative advantage) + Goodhart containment (a niche
  metric cannot be gamed outside its burrow) + compartmentalization (context overflow is
  the LLM failure mode).
- Falsifier: if niche-constrained runs repeatedly underperform a single generalist on the
  SAME tasks (quality AND scope-completeness) across ≥3 recorded tasks → re-forge via Maker.

## D-02 — No live orchestrator (documents are the only coordination medium)
- Alternatives: supervisor/orchestrator (LangGraph-style) · full peer chat · central state store.
- Why: stigmergy + blackboard lineage (cheap, auditable, replayable) + the Factorio wall
  (an orchestrator that refines itself is the efficient-cheat pattern) + R1 (transaction
  costs decide, and documents win at our scale).
- Falsifier: if coordination failures (misrouted tasks, NO NICHE storms, stalled handoffs)
  exceed wins across the first 5 recorded tasks → re-evaluate R1 with Coase numbers.

## D-03 — Results-as-prices (fate decided by documented outcomes, not opinions)
- Alternatives: central evaluator agent · Owner vibes · peer ratings.
- Why: Hayek (distributed knowledge, no central planner) + anti-Goodhart (the Human seat
  grades intent-distance, not the metric itself).
- Falsifier: if fate decisions (expand/refine/retire) systematically contradict later
  outcomes → the price signal is broken → revisit.

## D-04 — Council layer pre-budget (judge BEFORE spend)
- Alternatives: post-hoc review only · no judgment layer · judgment on every step.
- Why: decision cost doubles when changed later (Seat III) + RJ-001 condition 1 already
  pre-registers this as an experiment.
- Falsifier: pre-registered — if council-judged tasks show no accuracy/cost advantage over
  solo-executed ones in the first recorded pair → the layer is not earning its rounds.

## D-05 — Owner as constitution (R8 terminus; ratification, thresholds, signature)
- Alternatives: full autonomy · agent democratic vote · external human committee.
- Why: value alignment lives in ONE person here; the Human seat is the Goodhart
  counterweight; sovereignty is the product, not a bug.
- Falsifier: if the Owner becomes the measurable bottleneck (tasks stall on signature for
  days) → R8 stays (sovereignty is non-negotiable) but the DELEGATION surface re-forges
  (pre-approved budget classes, standing threshold values).

## D-06 — Paper-worn MICs first (phase A: Cline honors them manually) before code
- Alternatives: code-first (phase B immediately) · no MICs at all · full agent MICs.
- Why: RJ-001 condition 2 — declared paper swarm until structure proves itself; code
  before demand is speculative building (R7 spirit applied to tools).
- Falsifier: if manual honoring misses violations the MICs were designed to catch
  (measured in the first 3 result records) → phase B is DEMANDED by evidence, build it.

## D-07 — Law-simple doctrine (charters ≤ 1 page, powers ≤ 3, one-sentence niches)
- Alternatives: rich persona documents · framework defaults · no charters.
- Why: Sutton (fixed form, moving content) + cognitive load (a constitution nobody
  re-reads is dead law) + Kant check feasibility.
- Falsifier: if charters must constantly grow past one page to stay truthful → R2
  re-forging is failing → revisit the form, not the content.
