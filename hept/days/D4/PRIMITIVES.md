# PRIMITIVES (D4-Q01)

Default cap 6. Each: dry definition, why irreducible, what breaks if removed. Source: the five-field discipline (COULD_HAVE) + CHECKER3 bindings. No charter/VM vocabulary (CHECKER3 binding 1, 5).

## P1 — ATTEMPT (record unit)
**Definition:** one append-only file claiming a result, carrying the header fields [criterion, would-fail-if, price, receipt, flag] and an ancestor citation when it amends an earlier attempt.
**Why irreducible:** it is the only witness (WHY_REGRESS BK2 stop); without the unit there is nothing to refuse or accept — the object has no patient.
**If removed:** the doctrine has no carrier; refusal applies to nothing. Object dies.

## P2 — CRITERION (frozen test text)
**Definition:** a string fixed before the attempt runs, naming at least one output that would FAIL it (REOPEN BK3 amendment).
**Why irreducible:** it is what makes re-running possible and FAIL possible; the niche (refuse unrerunnable) is defined against its absence.
**If removed:** every claim wins by default; the niche is empty. Object dies (N1).

## P3 — RECEIPT (verbatim execution trace)
**Definition:** the in-turn command string plus its raw output, pasted unedited; the only lawful source of values (P14 cure).
**Why irreducible:** it is the provenance of every value in the record; both measured fabrications were exactly its absence.
**If removed:** the value-level lie has no wall (N2); every downstream check reads poison. Object dies.

## P4 — FLAG (UNVERIFIED verdict, terminal, propagating)
**Definition:** the state marking a claim as currently unfunded; terminal until the named gap closes; inherited by descendants (REOPEN BK5 amendment).
**Why irreducible:** it is the refusal made visible without deletion; deleting it cuts the diagnosis loop, funding it lies.
**If removed:** unverifiable claims are either silently kept or silently destroyed — both break N3. Object dies.

## P5 — PRICE (pre-committed check cost)
**Definition:** an integer (steps/minutes) fixed in the header before the check runs; someone must be able to pay it.
**Why irreducible:** without it, checking is unbounded or absent — both observed (BK4); with it, verification is an accounted act.
**If removed:** object survives but cannot scale (N4 conditional). Object wounded, not dead — still irreducible for the machine's filter set.

## P6 — EXPOSURE (measured chance to catch)
**Definition:** the count of times a mechanism or attempt was actually applied to a claim it could have caught (REOPEN BK7 amendment: N≥3 for judgment).
**Why irreducible:** it is the only lawful denominator for demotion/scoring; age, elegance, and design intent are illegal measures (L9).
**If removed:** demotion rules murder seeds or spare corpses arbitrarily (BK7 kill attempt). Day-4 filters lose their denominator.

## Non-primitives rejected at Q01 (pre-empting Q02)
- "gate" (charter word; the criterion+receipt pair replaces it), "wall/axis/burrow" (charter vocabulary — costume under CHECKER3 binding 5), "K-line" (optional schema sugar, not needed to generate moves), "Owner" (the discipline needs a payer, not a sovereign — payer is a role in P5).

# COSTUME KILL — D4-Q02

Substitution test per primitive: rename to the blandest word that preserves the definition. If the spine survives the rename, the primitive was branding; if the spine dies, the name was load-bearing (keep).

| Primitive | Bland rename | Spine survives? | Verdict |
|-----------|--------------|-----------------|---------|
| P1 ATTEMPT | "record" | YES — definition fully survives as "append-only file with header fields" | KILL THE NAME, keep the object: renamed to **RECORD** |
| P2 CRITERION | "test text" | YES — "frozen string naming a fail condition" survives | Renamed to **TEST TEXT** |
| P3 RECEIPT | "trace" | YES — "verbatim command + raw output" survives | Renamed to **TRACE** |
| P4 FLAG | "mark" | YES — "terminal unfunded state, propagating" survives | Renamed to **MARK** |
| P5 PRICE | "cost" | YES — "pre-committed integer cost" survives | Renamed to **COST** |
| P6 EXPOSURE | "count" | YES — "measured applications to catchable claims" survives | Renamed to **COUNT** |

## Result
- All six primitives survive the substitution test as MECHANISMS — none was a costume noun; the names were branding, the definitions were not.
- The spine that survives the rename is the five-field discipline wearing plain clothes: RECORD(TEST TEXT, TRACE, MARK, COST, COUNT).
- The words that died in Q01 pre-emption (gate, wall, axis, burrow, K-line, Owner) stay dead — they failed BEFORE the substitution test, at the definition stage.
- Machine naming rule going forward: primitives are called by their bland names; distinctive words may be re-attached in prose but never in definitions (D5-Q11 will re-test).
