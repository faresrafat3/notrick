## Anti-loop chaining rules
1. **No protocol twice in a row on the same target** — consecutive calls must differ in protocol AND target class (rule, record, mechanism, or rival).
2. **A call whose output restates its input** (no new gap-string, no move, no kill, no declaration) is a LOOP-CALL: the sequence must branch — either a different protocol or a recorded dead-end (a dead-end is a legal output; a silent skip is not).
3. **Every call consumes a real file as input and produces a file-recordable output** (gap-string, declaration, kill, invoice, amendment). Commentary is not an output.
4. **Max 3 consecutive calls without touching a raw workspace file** (outside hept/) — the sequence must keep contact with the corpus, not only with the week's own artifacts (anti-self-play, Expert line 12).
5. **Cycle guard:** returning to a target already visited in the sequence is legal only with a NEW anchor (new file, new fragment, new ruling) — otherwise the sequence ends there honestly.
