# BINDING CONSTRAINTS (D3-Q05)

Under VERDICT R1 (verification-discipline doctrine).

## Allowed moves (5)
| # | Move |
|---|------|
| A1 | Write a criterion as a frozen, pre-registered string BEFORE any attempt it will judge (HATCH 3 closed form). |
| A2 | Flag any success claim without a re-runnable criterion as UNVERIFIED (C0003). |
| A3 | Emit a receipt: verbatim command output only, in-turn, never retyped values (C0005/C0006 cure). |
| A4 | Price a verification act before running it (C0007): state who pays and in what currency (time/steps). |
| A5 | Demote any mechanism that produced zero catches in its life to dead weight (D2 DEAD_WEIGHT protocol). |

## Illegal moves (5)
| # | Move |
|---|------|
| X1 | Run a gate whose criterion was selected or edited after seeing the attempt (self-owned gate — RULES.md:25 violation). |
| X2 | Type a hash/number/value into a record that was not produced by an in-turn command (P14 violation class). |
| X3 | Retro-log an approval to legalize a write that already happened (HATCH 2 closed form; DS8). |
| X4 | Treat a queue entry, plan, or charter text as if it were a result (C0008/C0013 vs D0005/FR02). |
| X5 | Reconcile a contradiction by relabeling both sides as "lenses" (L12) — verdicts must cut, not blend. |

## Standing constraints (5)
| # | Constraint |
|---|-----------|
| S1 | Every success claim in any hept/ artifact carries an id + path anchor or is UNPAID (L8). |
| S2 | The workspace (notrick doctrine) outranks hept/ ledgers, which outrank any canon sentence (authority order). |
| S3 | A claim that intersects no existing anchor is NEW and guilty until earned (R10 spirit, operationalized by A1-A2). |
| S4 | Verification cost is budgeted; unlimited checking is a violation of C0007 economics, not a virtue. |
| S5 | The doctrine may not claim a state it has never executed: no "achieved" language without a run record (FR02/K4 discipline). |

## Effect on Day 4
The machine (Day 4) must generate moves within A1-A5 and refuse X1-X5; primitives that cannot express this constraint set are costume.
