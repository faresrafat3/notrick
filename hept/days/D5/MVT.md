# MINIMUM VIABLE THEORY (D5-Q09)

## The MVT (shortest form that still refuses)

**A claim is acceptable only if: (1) its test was written before it ran and names an output property that would fail it; (2) its recorded values are pastes of real command output; (3) the check was paid for; (4) a failed-or-unrunnable test marks the claim — and the mark inherits to everything built on it; (5) records are never rewritten, only superseded; (6) mechanisms are retired by counted tries-and-catches, never by taste.**

Six rules. Everything else this week produced is support: ledgers, runs, rivals, repairs.

## Is the MVT stronger?
- It loses nothing load-bearing: every repair from EXPERT (X9-X12, I6, staleness, marker-restriction) fits inside rules 1-6 as clauses.
- It is checkable by a stranger in one read (the D4 done-when standard).
- The ornate version's formal layer survives ONLY as tooling for running the MVT at scale — it no longer claims to BE the theory.

## Demotion recorded
The D4 machine (primitives → schema → generators) is demoted from THEORY to IMPLEMENTATION of the six-rule MVT. If a future agent finds the implementation insufficient, the MVT is what they must amend — not the tooling. GRAVEYARD row follows in Q10 for anything that fails its own exposure count.
