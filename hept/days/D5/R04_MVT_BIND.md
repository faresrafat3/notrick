# THE SEVEN-RULE MVT, BOUND (D5-R04)

The theory as it stands after Day 5. This is the file the Day 6 architecture implements and the Day 7 canon states. Every clause carries anchors.

## RULE 1 — Pre-registered criterion
A claim's test is frozen before the claim runs, and names at least one output property that would fail it.
- Anchors: BK3 amendment (REOPEN.md) · X6 (INVARIANTS) · X9 reachability (EXPERT repair) · X11 staleness (EXPERT repair) · evidence DS-P-001 (D2 HOSTILE/PRESSURE_RANK).

## RULE 2 — Paste-only values
Every value in a record is a verbatim paste of in-turn command output; no retyped, remembered, or reasoned values. Cross-class re-run mismatch = fabrication.
- Anchors: V-001/V-002 (QUOTES Q0001-Q0002; EX1.md) · P14 (D2 DEBTS) · I1 byte-compare (INVARIANTS) · Rule 7 environment clause (GRAFT.md, B1).

## RULE 3 — Priced checks
A check runs only after its cost is committed; post-hoc pricing is illegal; cost=0 and cost=∞ are both illegal.
- Anchors: BK4 + D0021 (WHY_REGRESS) · X7 (INVARIANTS) · RUN04 self-pricing (RUNS.md).

## RULE 4 — Terminal marks that inherit
A failed or unrunnable test marks the claim UNVERIFIED with a named, exact gap-string; the mark is terminal until that exact gap closes and inherits to all descendants.
- Anchors: BK5 amendment (REOPEN) · I3 edge-walk (INVARIANTS) · B3 gap-translation hatch (BREAKS) · RUN11 UNRUNNABLE subdivision (RERUN_INSTRUCTIONS).

## RULE 5 — Append-only supersession
A judged record is never edited; corrections are new records citing their ancestors; the citation graph is acyclic.
- Anchors: V-002 silent-overwrite (D2 DEBTS) · I4 hash check + I6 acyclicity (INVARIANTS; EXPERT repair) · R6 constrain (RELATIONS_OPS).

## RULE 6 — Counted mechanism retirement
Mechanisms are retired or kept only by counted (tries, catches) inside a pre-declared exposure class; age, elegance, intent, prestige are illegal grounds.
- Anchors: BK7 + D0022 (WHY_REGRESS, REOPEN) · X8/X10 (INVARIANTS; EXPERT repair) · O6 demotion (RELATIONS_OPS) · B4 count-gaming (BREAKS) · GRAVEYARD anti-resurrection.

## RULE 7 — Environment declaration
A PASS names the environment class its check ran in; a verifier may re-run in a different class; cross-class output mismatch marks the original UNVERIFIED.
- Anchors: GRAFT.md (the one recode, budget 1/1) · B1 command forgery (BREAKS) · NC1 defeat-observation (NERVOUS).
