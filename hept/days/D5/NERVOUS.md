# NERVOUS COMMITMENTS (D5-Q12)

Five claims the theory still makes that can be wrong. Each sharpened to a named observation that would defeat it. If a friend would not worry about one, it was not sharpened enough.

## NC1 — The six rules are sufficient for refusal (nothing essential is missing)
Can be wrong if: a fabrication class appears that walks past rules 1-6 — e.g., a claim whose criterion, paste, and price are all real but whose COMMAND semantics lie (the P14 hole, D5-Q04 MISS).
Sharpened defeat-observation: one real record where all six rules pass and the claim is still false. Currently zero such records; the command-forgery hole is the live candidate. (feeds B-case Q13)

## NC2 — BK5 propagation is well-founded (marks inherit correctly)
Can be wrong if: inheritance produces a false-positive chain — an ancestor marked UNVERIFIED for a gap whose closure does not actually affect a descendant's validity, yet the descendant stays flagged forever (over-inheritance strangling legitimate work).
Sharpened defeat-observation: a descendant whose own trace is complete and self-sufficient, held UNVERIFIED only by an unrelated ancestor gap, with no laundering involved. If such a case appears and the rule cannot distinguish it from laundering, BK5 as stated is wrong.

## NC3 — Counted retirement (BK7: tries≥3, catches=0 → retire) converges on the right mechanisms
Can be wrong if: exposure is systematically biased — mechanisms applied only to easy claims bank catches cheaply, while genuinely strong mechanisms face only hard claims and get retired. (Expert line 4; X10 denominates but does not de-bias.)
Sharpened defeat-observation: a retired mechanism whose catch class later appears via another route (post-retirement catch through a different mechanism) at rate >0 across ≥5 occurrences.

## NC4 — The refusal scope is the right scope (governance/stall is genuinely out)
Can be wrong if: the EX2 blind spot is not peripheral but central — i.e., a ledger where every individual record is clean under the six rules while the SYSTEM verdict is wrong because judgment accumulation (stall, cascade, queue) dominated. The theory would then be checking the bricks and ignoring the building.
Sharpened defeat-observation: a full-rule-compliant corpus whose net output claim is false for stall reasons, with no rule violation anywhere. One such case defeats the scope claim, not just a parameter.

## NC5 — One-writer theater (S2) is answerable by a multi-writer run
Can be wrong if: multi-writer operation does NOT change the catch rate or failure topology — i.e., the catches really were a property of the single writer's care, and adding writers changes nothing except cost. Then the doctrine is hygiene with a sociology field, and S2 was right.
Sharpened defeat-observation: a documented multi-writer ledger where X1-X12 violations and catches distribute across writers in a pattern impossible for a single writer (e.g., a catch of writer A by writer B with no shared context). Zero such pattern after N≥3 real multi-writer runs = S2 wins the fork.

## Status
All five are live; none has a defeat-observation on record yet. NC1's candidate (command forgery) and NC5's experiment (multi-writer) go to Q13 break cases.
