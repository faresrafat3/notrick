3 cheap hatches the text already uses, closed by restating so they cannot wriggle.

## HATCH 1 — "The version never moves backward"
Old form: "The version NEVER moves backward" (VERSION.md:20).
Escape: no movement has EVER happened, so the law claims a property of an empty sequence.
Closed restatement:
> Every stamping event must be either the activation of a new locked gate (bit flips 0→1) or a re-stamp of an already-open gate with no digit change. Any stamp whose digit count decreases is void; any attempted stamp without a logged gate event is refused by MIC-11-like ID check before it lands. First-ever stamp still owed, and until it happens the law is UNTESTED, not proven.

## HATCH 2 — "approved-docs moment"
Old form: "approved-docs moment" appears ~10× in CONTEXT tail as the magic way doctrine changed.
Escape: because the moment is defined after the writes (retro-logging), ANY write can be retro-fitted to a "moment".
Closed restatement:
> An approved-docs moment must be a single line, logged BEFORE the first write it authorizes, stating the exact file list and the Owner line it restates. A write conforming to a moment logged after it is a violation unless the item is re-submitted through the guest write-path (proposals/). Retro-logging is banned as a doctrine-change channel.

## HATCH 3 — "gate it does not own"
Old form: "A gate owned by the claimer is not a gate" (RULES.md:25).
Escape: "owner" is never defined; in a one-writer garage (only the rehearsal creator has run a gate), every gate trivially belongs to the claimant.
Closed restatement:
> A gate's owner is the role that selected the criterion text BEFORE the attempt began (a frozen, pre-registered string — pr-005 R-1). If the same entity that wrote the attempt also selected the criterion after seeing the attempt, the gate is owned by the claimer and its PASS carries no weight. Writer and gate-selector being distinct is necessary, not sufficient: the criterion must also be frozen and logged before the attempt starts.

## Result
- HATCH 1, 2, 3 closed. Each restatement removes the wriggle by making the escape condition itself illegal.
