# WHAT-MUST-BE-LOST (D2-Q11)

5 things a real later verdict (Day 3) would have to abandon to be honest.

| # | Item | Why it must be lost | Evidence |
|---|------|---------------------|----------|
| 1 | "documents are the only voice" as a descriptive claim | False-by-record: decisive rulings all live on chat lines; files freeze afterward (K1/B5). A verdict that keeps it as description is a noble lie. | K1, B5, DS7 |
| 2 | "no live orchestrator" as an achieved state | No multi-agent run exists; the owner-chat + scribing is the only coordination (D0005/FR02). A verdict must drop the achieved-state reading and keep only a design-posture reading. | D0005, FR02, C0013 |
| 3 | The version register as a "distance-to-zero" measure | It has measured nothing: no move, no gate, no event (D0008/A5). A verdict must lose the measure claim and keep only the law's procedural form (or kill the law). | D0008, A5 |
| 4 | "The gate is the only truth" as a solved epistemic rule | The one executed gate was self-owned (F12); "truth" undefined (D0003). A real verdict abandons the word "truth" for "verified" and redefines owner. | D0003, F12, FR01 |
| 5 | Integrity pins as a prevention mechanism | Pins never prevented a fabrication; they only verify after (K8, DS2). The verdict must abandon prevention-saying and treat pins as what they are: post-hoc audit trails. | K8, DS2, C0005 |

## Notes
- Each loss is forced by recorded evidence, not by taste. These are the costs of a verdict that does not lie.
