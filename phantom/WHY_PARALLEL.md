# WHY_PARALLEL — what would be lost if Phantom had read a finished canon first
1. The duplicates: a canonized LOG gets deduplicated before reading; the double OP-023/OP-027 lines would never be seen as practice.
2. The blanks: knowing the doctrine first, the empty P3 line reads as "pending", not as the disk's actual state.
3. The failed pick: F09 would be pre-absorbed as "a versioning anecdote" instead of an unparsed instruction from the scale's own author.
4. The failed tagline: F10 arrives pre-labeled "known finding"; the label replaces the quote.
5. The fabricated hash: a finished canon has no fabrication incidents; F03/F04 would be absent from it entirely.
6. The silences: "2 signed silences" survives only in the log; a summary converts silence into content.
7. The unrecoverable header: loss itself is the datum; canons keep recoveries, not holes.
8. The ranking: without a canon, low-prestige lines stay load-bearing; a canon ranks by thesis-contribution and P-01..P-14 sink.
