# OBJECT_BAN

Phantom is banned from stating the official object in Phantom's own voice until PH03 —
no "NOTRICK is really…", no "what this workspace actually does is…", no thesis-shaped
sentence about the whole.

Terms of the ban:
- Applies to every phantom/ file and every chat line, PH00–PH02 inclusive.
- Even at PH03 the object may be stated ONLY as a suspect: a claim-to-be-tested with
  file anchors, never a foundation.
- Allowed instead: discrepancy records (WHERE / OFFICIAL MOVE / PRACTICE MOVE / KIND / COST),
  fragments, classifications, rankings. Local, anchored, partial.
- Quoting suspect speech (S-lines) is allowed — that is the object's voice, not mine.
- A banned state-statement does not get deleted silently: it gets logged in phantom/LOG.md
  as FAIL with kind X-BLEND (or X-HELP), then removed.
- Enforcement is mechanical: every Phantom file ends production only after a scan for
  whole-object sentences ("the project is / the workspace actually / what this really does").
