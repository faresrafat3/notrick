# HANDOFF_PH03 — practiced-object candidates (op 09)
Built from example-laws (EXLAW) + repeats (REPEATS) + the early engine — NOT from titles,
abstracts, or charter self-descriptions. PH03 may state the object ONLY as a suspect.

CANDIDATE-1 · THE REFUSAL ENGINE (from E04 + E05 + R08 + B6)
  The object practiced is a refusal machine: values it cannot author stay blank, inputs
  that fail grammar are refused, powers that lack provenance are not scribed. Its most
  reliable outputs are refusals; its currency is the deferral.
  Cost if practice is law: a system whose only mastered verb is "no" — the charters'
  positive powers (forge, execute, compose) are costume.

CANDIDATE-2 · THE SECOND-PASS MIND (from E02 + E09 + R06 + engine step 2)
  The object practiced is not the first writer but the re-reader: every catch, every
  audit pass, every filed violation happened on review, never at write time. The
  "operator" and the "checker" are the same writer at different passes.
  Cost: supervision is not an architecture, it is reading twice — the four-layer stack
  is the costume of a reread.

CANDIDATE-3 · THE HOLE KEEPER (from E03 + E08 + S02 + B4)
  The object practiced keeps wounds open on principle: contradictions found and not
  fixed, loss recorded as unrecoverable, entries that cannot close. The record's value
  is its visible damage, and repair would erase the evidence.
  Cost: the official goal of a clean, ratified, moving-forward doctrine is inverted —
  the practice optimizes for the legible scar.

CANDIDATE-4 · THE WAITING WRITER (from R10 + S05 + seam-5 + B3)
  The object practiced is a waiting room: its most stable content is what cannot be
  filled (P3, ruling fields, version pick), its most repeated act is handing the same
  pick to the same authority twice. Production continues only in the margin of the wait.
  Cost: the version scale, the gates, and "distance to zero" are the costume of a stall.

CANDIDATE-5 (weak, UNCERTAIN — do not promote without a second instance) · THE
  NUMBER-AS-HONESTY TOKEN (from E06 + E07 + R03 + seam-3): precision printed against
  one's own interest functions as the proof-of-honesty. Cost: honesty is performed in
  the loss column, and the thesis harvests it (seam-2).

Discipline for PH03: each candidate is a SUSPECT until it has ≥3 discrepancies of legal
kinds with file anchors. Any statement of "the object" outside the suspect frame violates
OBJECT_BAN. Watch anti-clone: none of these may become a new framework name.
