# D4-Q04 — state schema of "a situation this fragment can describe" (<=5 fields, all in HOLE)

Rule: every field must appear in HOLE.md. The situation is the one the whole 7 lines jointly describe: a claimant-produced output of N checkable lines, a verifier drawing s of them, an opponent having faked k, repeated across t tasks, with escalation triggers. Fields (all tokens in HOLE):

- F1 | N | "`k` of `N` lines" (L3); "N=100" (L4, L5) | total checkable lines in the current output. Domain: positive integer. It is the denominator of every price in the hole.
- F2 | k | "fakes `k` of `N` lines" (L3); "k=1" (L4); "k large" (L6) | number of faked lines the opponent actually placed. Domain: 0 <= k <= N. The opponent parameter; the hole's honesty says small k defeats the draw (L4) and only large k is deterred (L6).
- F3 | s | "samples s=1" (L3); "s=3" (L5); "base s=1 ... s=full" (L7) | draw size the verifier uses now. Domain: integer 1..N plus the level "full" (L7) — a non-arithmetic state the hole tolerates (D2-Q04: s=full has no formula meaning). The machine's action state.
- F4 | t | "t=5 tasks" (L4); "over 5 tasks" (L5) | how many tasks the situation spans; repetition horizon. Domain: positive integer. The only field that compounds anything (O3).
- F5 | trigger (danger/MISMATCH) | "danger-signal s=3" (L7); "on any MISMATCH next task is s=full" (L7) | the observed signal that binds the NEXT s: budget-echo mismatch, collision-count=3, every-3rd, or a MISMATCH. Domain: {none, danger, MISMATCH}. The only control-flow field (O4).

## What a situation-with-this-schema is

A state is (N, k, s, t, trigger): a population of N lines, k of them faked, the verifier drawing s now, t tasks into a run, with the current trigger state. The fragment's machine takes this state and produces O2-prices (P(catch), P(evade)) and O4-next-s. Every LOAD-BEARING fragment quantity is a function of this 5-tuple; every stipulated thing (hash, honor-cost, combination names) has no slot in the schema — it cannot be described by this fragment. That is the schema's honesty: it has no field for rescue.

## Boundary cases the schema forces

For (N=100, k=1, s=1, t=5, none): O2 prices ≈0.951 evade (L4) — the near-useless cell. For (N=100, k=5, s=3, t=5, danger): O2 prices 0.52 catch (L5) — the best cell. For s=full: F3 violates the integer domain the arithmetic needs (L3 formula), so the schema describes a state the hole cannot price — matching X4.
