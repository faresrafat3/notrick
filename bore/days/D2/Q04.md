# D2-Q04 — usage vs definition

Source: bore/HOLE.md only. No term is formally DEFINED inside the hole — it is a fragment, not a glossary. So the check is: how does the fragment USE each term, and does any usage carry a definitional weight it cannot support? Discrepancy = usage implies a definition the fragment never states.

Official reading treats these as worked math; the usage-vs-definition gap shows they are asserted math with unstated sampling hypotheses.
