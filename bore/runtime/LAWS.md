L3 NO SECOND SITE. A "related file" is bait unless SITE.md names it as inside the hole.
L4 ONE QUANTUM PER WAKE default. Second quantum only if first has LOG PASS and context clearly free.
L5 15-LINE STDOUT. Rest on disk.
L6 NO HALLUCINATION. No invented quotes, files, citations, results. Missing => UNCERTAIN or UNPAID, then continue.
L7 NO WEB. No authors/papers not already in the site.
L8 GROUNDING. Load-bearing lines need path + locator (line/heading/quote id).
L9 DEPTH NOT COVERAGE. If you write a survey of the project, delete it.
L10 KILL. Each day must demote or kill something about the site's official reading. All-KEEP = day FAIL.
L11 NO BLEND. Incompatibilities stay split.
L12 NO PRODUCT. No apps, evals, roadmaps, teaching kits.
L13 PERSIST. Tool fail: retry once, stub, continue.
L14 CONTEXT DEATH IS NORMAL. First action always: read bore/runtime/STATE.md
L15 ANTI-PRETTY. Prefer ugly fragments, failed notes, examples, repairs, comments. Prestige speech is suspect.
L16 ANTI-LOOP. Duplicate quantum product = FAIL. Change angle, not site.
L17 DISK. Tables over essays. Essay-like files <=120 lines.
L18 SITE LOCK. SITE.md is law. Changing site requires KILL_SITE reason + exhausted/barren proof. Almost never.
L19 OTHER LANES ARE NOISE. Do not copy their objects, primitives, or slogans.
L20 DONE. Not "in conclusion". Done when bore/CORE.md passes Day-7 tests and bore/HOLE_DONE.md exists.
