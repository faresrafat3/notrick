1. Extract {authority-type, claimed location, verbatim anchor} from T.
2. `grep -F '<anchor>' <claimed constitutional location>` — moments → CONTEXT.md decision-log tail; signatures → RATIFICATION-BATCH-001.md; version → VERSION.md:1; rulings → the Owner-typed field of the artifact itself; violation closes → the Owner's own act (none exists yet).
