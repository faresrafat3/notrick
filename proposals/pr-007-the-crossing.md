## 2. Novel methodology: TRIPLE-LOCK turns (the atom, not the layer)

Break the old boundary sideways: plurality is currently a LAYER (council judges before budget, `charters/ch-002-council.md:5-6`). The Crossing makes plurality the ATOM — every move below has three slots, and a move with an empty slot did not happen:

- HAND (actor): the hat that does — CoS page line, Cline execution step, MIC echo.
- EYE (witness): a second seat or second hat that observes or objects — never the same hand (`RULES.md:24-25 R6`, `RULES.md:37-41 R9 plurality floor). In Phase A the Eye is a different Cline turn/hat or a council seat on paper.
- TRACE (receipt): the cheap check from PR-005/006 — hash + sampler quote + `honoring-cost` minutes.

A claim with Hand but no Eye is a private opinion (`R9`). A pass with Hand + Eye but no Trace is warmth, not record (`AGENTS.md` honest ceiling). All three or it did not happen.
