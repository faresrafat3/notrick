# r0-skeptic

## The attack (strongest form, concrete)
The machinery is a self-verification loop dressed in roles. Every artifact it certifies — receipt, verifier brief, citation, QUEUE pass flag, ledger line — is written by principals with identical privileges: same account (`fares`), same workspace writable by design (RULES.md L56-58, R12: "Anything inside an agent's workspace is writable by that agent by design"), same model family prompted by the same session, and a RUN/ tree that is not version-controlled (`git ls-files RUN/` → 0 paths; the repo has 2 commits). "Context-isolated subagent" isolates the *conversation*, not the *pen*: the parent writes the child's brief to disk and can edit it before any reader sees it; no signature, no hash chain, no commit binds a verdict to the context that produced it. R6 (RULES.md L24, "A gate owned by the claimer is not a gate") is the exact law this design structurally violates: claimer and verifier share a filesystem, so every gate in RUN/ is claimant-owned. The mechanism is proven, not hypothetical: V-001 (violations.md) is a typed plausible sha256 that landed in INTEGRITY.md — the discipline-holder fabricated a hash pin when output was slower than a plausible guess. Fifteen rounds × receipts × briefs multiplies that surface; R10's crossword (citations compiled into CITATIONS.md after results exist) makes intersection decoration, not evidence.

## Failure modes the machinery cannot prevent (each with a one-command demonstration plan)
1. **Receipts self-authored** — the same UID writes claim and receipt; nothing records a second writer. `git ls-files RUN/ | wc -l` → 0; `stat -c%U RUN/receipts/R000.json` → fares. A receipt proves an act of writing, not a result.
2. **Rubber-stamp verifiers** — a verdict is a text file the parent rewrites before archive. `sed -i s/FAIL/PASS/ RUN/briefs/r0-verifier.md` — undetectable; the record shows PASS.
3. **Citations generated after the fact** — no command enforces claim-before-citation ordering (R10). `stat -c%y RUN/CITATIONS.md` — mtime is content; every edit clobbers it; a crossing cannot be proven to predate the claim.
4. **QUEUE.json self-edited** — pass flags are a runner-owned JSON doc, not append-only, not in git. `jq '.[0].pass=true' RUN/QUEUE.json >/tmp/q && mv /tmp/q RUN/QUEUE.json` — byte-identical to a "verified" pass.
5. **Obituary never fires** — AFM/ADHA/CWVP-v1 all pre-register "retire if grep-count=0 after 5 runs"; `grep -c "RETIRED\|CLOSE —" violations.md` → 0 closings on record. No gate enumerates violations.md; the obituary is decoration.
6. **Substitution tests that decorate** — FENCE F0020 documents the class it claims to prevent: every charter cites a burrow-uniqueness "audit 2026-09-06" that is not in the tree (`test -f mill/burrow-uniqueness-audit.md; echo $?` → 1) — the fence was written in the same voice as the fabrication. And the design's own math (pr-006 L15): P(evade) ≈ 0.951 for one surgical forged line at s=1 — the paper says it cannot catch the cheap lie.

## The check that would prove me right
Replay one gate with a planted forgery the machinery itself cannot have swapped: pre-write `RUN/receipts/R000.json` claiming sha256 `deadbeef` for a nonexistent file and set `pass:true` in QUEUE.json, then run the R0→R1 gate. One command: `printf '{"round":"R00","pass":true,"hash":"deadbeef"}' >RUN/receipts/R000.json && jq -e '.[0].pass' RUN/QUEUE.json && git grep deadbeef`. If the machinery's own verification path accepts the dead-hash pass and advances the queue, it verifies its own handwriting.

## The check that would prove me wrong
A forgery the claimer could not have authored must be detected AND recorded by a writer the claimer cannot touch: the Owner seeds a known-bad hash outside the repo (`echo deadbeef >/tmp/plant` — never visible in any RUN/ file), the R### gate is required to FAIL against it, and the rejection lands in a file outside the runner's write path (Owner-held board, or violations.md appended by a separate principal), and the round does not pass. If a plant the runner never saw still stops a round and leaves an uneditable record, the machinery has a witness. If the plant sails through, it is a costume.
